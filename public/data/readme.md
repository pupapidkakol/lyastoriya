# ЛяСторія — шрифти та кольори

Дизайн взято з макета «ЛяСторія — мінімалістичний редизайн» (Figma).
Значення нижче перенесено в **`public/tokens.css`** як CSS-змінні. Змінюєш тут — міняй і там.

Підключення на сторінці (перед `css/style.css`):

```html
<link rel="stylesheet" href="tokens.css">
<link rel="stylesheet" href="css/style.css">
```

`tokens.css` сам підтягує шрифти з Google Fonts, тому окремі `<link>` на шрифти не потрібні.

## Шрифти

| Токен | Шрифт | Де використовується |
|---|---|---|
| `--font-sans` | **Inter** 300–700 | увесь текст, заголовки (700), кнопки (500–600) |
| `--font-mono` | **JetBrains Mono** 400–500 | службові мітки `01 / ІГРИ`, дати, номери, підписи до фото |

> Увага: у PDF макету шрифти вбудовані як контури (Type 3), тож назви не збереглися.
> Inter + JetBrains Mono — це найближчі відповідники до вигляду макета і ті самі шрифти, що були на сайті.
> Якщо в Figma інші — достатньо змінити `--font-sans` / `--font-mono` у `tokens.css`.

Типографіка: h1 — 700, ~56–64px, `letter-spacing: -.025em`; h2 — 700, ~32–40px; мітки — mono 10–11px, `letter-spacing: .2em`, `uppercase`.
